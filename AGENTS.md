# ClashHQ Agent Rules

1. `CLASHHQ_SPEC.md` is the authoritative project specification.
2. Work on only the currently authorized phase. Never advance phases without explicit human approval.
3. Follow the locked technology stack, security rules, data principles, and schema boundaries in the specification.
4. Treat unknown API capabilities as unverified. Never fabricate evidence, test results, historical data, or successful operations.
5. Protect credentials and personal data. Never commit API keys, raw authenticated captures, real clan/player identities, or unsanitized fixtures.
6. Never perform destructive database operations, credential capture, backup deletion, or other sensitive operations without the required authorization.
7. Before implementing a phase, identify its scope, schema changes, acceptance criteria, and tests.
8. Run the relevant tests and report actual results. Clearly distinguish completed, failed, skipped, and unverified checks.
9. Do not silently change the specification. Explain conflicts and proposed scope changes before proceeding.
10. Stop at every phase gate and wait for explicit approval before moving forward.
